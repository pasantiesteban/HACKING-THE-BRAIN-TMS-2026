# Surveys and Recruitment Materials

## Description

This directory contains the recruitment materials and participant surveys used in the study.

The contents of this directory are organized as follows:

* `TMS Recruitment Poster.png` contains the recruitment poster used to advertise the study.
* `Pre-Screening-Eligibility-Survey.docx` contains a copy of the pre-screening eligibility survey. Individuals who did not satisfy the eligibility criteria specified in this survey were not invited to participate in the study.
* `Post-Study-Survey.docx` contains a copy of the survey administered after each experimental session. This survey collected participants' feedback on their TMS experience, as well as demographic and background information.
