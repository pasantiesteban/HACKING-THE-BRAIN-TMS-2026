# Raw Data

## Description

This directory contains the raw data collected during the study, including programming task data, working memory task data, field notes, and post-study survey responses.

The contents of this directory are organized as follows:

* `coding-tasks-data\` contains two subdirectories: one with participants' programming task data and one with participants' behavioral data collected during the programming tasks (e.g., keystrokes and file-opening events).
* `nback-tasks-data\` contains the raw working memory task data for each participant. Most participants have three ZIP archives corresponding to one practice session and two experimental sessions (one for each study session).
* `post-study-survey-responses\` contains a CSV file with participants' raw responses to the post-study survey.
* `field-notes\` contains a CSV file with the field notes recorded by a researcher during each study session.
