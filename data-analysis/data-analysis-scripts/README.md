# Statistical Analysis Scripts by Research Question

## Description

All statistical analyses were conducted in R. This directory contains the scripts used to analyze the data. Researchers who wish to inspect the results without rerunning the analyses can view the knitted HTML documents (`.html`), while those who wish to reproduce the analyses can execute the corresponding R Markdown scripts (`.Rmd`).

The contents of this directory are organized as follows:

* `NBACK-RT-analysis.{Rmd,html}` contains the analyses for Research Question 1.
* `METHOD-SYNTHESIS-RT-analysis.{Rmd,html}` contains the analyses for Research Questions 2 and 3.
* `ALL-Accuracy-analysis.{Rmd,html}` contains the analyses for Research Question 4.
* `BH-Correction.{Rmd,html}` contains the Benjamini–Hochberg correction applied to the reported p-values.
* `EXPLORATORY-analysis.{Rmd,html}` contains the exploratory analyses discussed in the Discussion section.
